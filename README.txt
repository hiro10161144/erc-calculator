ERC計算機（個人用 / iPhone対応）

内容:
index.html / manifest.webmanifest / sw.js / icon-180.png / icon-192.png / icon-512.png

Windowsでの確認:
index.html をChromeやEdgeで開き、16桁のコードを入力してください。

iPhoneで使う:
これらのファイルをすべてHTTPS対応のWebサーバー（例: GitHub Pages）にアップロードしてください。
Safariで公開URLを開き、共有 → ホーム画面に追加 を選びます。
HTTPSで一度開いた後は、PWAのキャッシュが成功していればオフラインでも起動できます。

計算例:
20180E00F1FFB81F → CA04E77E
100651200205355F → DCA9E74F

注意:
これは個人利用向けの無料版です。GitHub Pagesなどに公開すると、アクセスした人は計算式を確認できます。
有料販売版ではこのHTMLをそのまま公開せず、計算処理をサーバー側に移し、Stripe決済確認後に限定実行してください。
